# DeFAI Agentic DEX Launchpad

- [ ] **Launchpad discovery and filtering** — Users can discover DeFAI agents and agent-powered DEX strategies through a searchable, filterable launchpad directory.
  - Acceptance: the directory exposes search, lifecycle filters, and strategy/category context without leaving the main experience.
- [ ] **Trust-first project evaluation** — Projects surface concise performance, risk, liquidity, audit, and trust-signal summaries.
  - Acceptance: cards and detail surfaces show comparable metrics, visible risk labels, and audit/trust cues.
- [ ] **Launch lifecycle and featured opportunities** — Upcoming, live, funding, and launched states are clear, with featured and trending launch opportunities.
  - Acceptance: each launch shows its lifecycle state plus raised amount, participants, liquidity, and time remaining where relevant.
- [ ] **Agent detail and participation context** — Users can inspect strategy summaries, token information, activity, transparent risk disclosures, and their own participation context.
  - Acceptance: the dashboard includes a portfolio/activity rail and detail/participation affordances.
- [ ] **Interactive token launch flow** — Users can move through project details, tokenomics, launch parameters, review, and confirmation.
  - Acceptance: a guided multi-step flow exposes those stages and ends in an explicit confirmation state.
- [ ] **Responsive crypto-native visual system** — The product uses a calm, high-trust crypto visual system with dense information hierarchy, responsive layouts, and polished micro-interactions.
  - Acceptance: the primary dashboard remains usable across desktop and mobile widths with consistent status, metric, and action patterns.
